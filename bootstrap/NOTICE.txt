INSTALLATION AND SCANNING

If you approve, the installer downloads the selected official DEB on your
computer, verifies its size and SHA256 against the CI-scanned source record,
unpacks it without executing Debian maintainer scripts and builds a local RPM.
Only the final package-manager installation or removal requests system
authorization. Run setup as your normal user.

Official metadata determines the selected channel, version and source hash.
A configured third-party download fallback may supply only the same pinned
DEB and must match its official size and SHA256; it does not select versions.

ClamAV runs only in the GitHub Actions VM. It is not installed or run on your
computer. CI updates ClamAV signatures and scans the official DEBs and their
extracted contents. Malware detections, scan errors and exceeded limits stop
publication. PUA-only matches are reported separately. The installer includes
a scan record bound to the official source hash, not the application payload.
A clean scan and matching hash cannot establish absence of every threat or
future vulnerability and do not grant legal permission.

Downloading, hash verification, unpacking, local RPM compression and package-
manager dependency resolution can take time. Progress messages identify the
current stage; waiting does not mean a local antivirus scan is taking place.

Stable is selected by default for setup and update. The explicit -unstable
option selects testing for that operation. Both channels replace the same
local client package; concurrent stable/testing installations are unsupported.
Returning to stable can install an older version.

CONSENT, DECLINING AND MIGRATION

Approval requests this local installation after review of this notice and
Spotify's applicable terms. Approval is specific to the notice and selected
source/version context; an update can require renewed approval.

Declining stops download, build and launch. If this project's current local
client package is installed, its removal is requested through system
authorization. If authorization is denied or removal fails, it may remain
installed, but this launcher refuses to run it. The small installer RPM can
be removed separately using your system package manager.

Before downloading, the installer checks for conflicting packages. A previous
local target is eligible for replacement only when identified as this
project's own package. Unrelated LPF or other vendor installations are not
silently removed. Review the proposed package-manager transaction before
authorizing it. Earlier configuration files and historical evidence are
preserved; migration does not carry forward an earlier consent record.
