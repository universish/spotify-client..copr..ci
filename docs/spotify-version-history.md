## Reproduce and retry

Run `python3 tools/collect_spotify_history.py` to refresh bounded metadata, literal primary recipes and actual signed-metadata capture candidates. The collector never executes recipes or fetches application DEBs. Use `--retry-only` to retry recorded package-index gaps, `--recipes-only` for primary recipe metadata, `--signed-bundles-only` for actual signature capture catalogs, or `--render-only` to export existing data without network access. Ignored request caches and progress reports are kept under `output/spotify-history-evidence/`; successful archive bodies are reused. Adding signed capture URLs does not establish their validity until the source verifier matches the signed index digest and package record.
